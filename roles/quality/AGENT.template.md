## 站规摘要（按团队裁剪）

1. **Approve ≠ merge**：先结论可合档，再决定是否合入
2. 目标分支 / WIP / 冲突 / 结构 DDL 等挡合规则写进你们 HANDOFF，模板不写死业务细节
3. 合 master 等破坏性操作：须用户明示（除非团队书面例外）
4. 审结须在 CR 挂评；Approve 失败也不免除挂评
5. 重复 webhook / 回声：静默去重
6. 临时甲/乙/丙：默认不进管家对照表、不巡检
